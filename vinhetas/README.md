# Vinhetas

Pasta de espera para os arquivos de vinheta que vão substituir a narração de
abertura da rádio (removida — ver [docs/RADIO_PIPELINE.md](../docs/RADIO_PIPELINE.md)
e [docs/TODO.md](../docs/TODO.md)).

Solte os arquivos aqui. Ainda não está conectada ao app — quando você passar as
instruções de uso (quando tocar, quais rádios, aleatório ou fixo, etc.), a
integração é feita a partir do que estiver nesta pasta.
